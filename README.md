# 이미지 필터 테스트 (OpenCV)

브라우저에서 실제 **Python + OpenCV**(Pyodide)로 이미지 필터를 실험하는 단일 HTML 프로그램입니다.
설치 없이 `index.html`을 더블클릭해서 열면 됩니다. (처음 실행 시 인터넷에서 Python/OpenCV를 내려받느라 몇 초 걸립니다.)

## 화면 구성

### 필터 테스트 탭
- OpenCV 분류 체계 치트시트(11개 분류, 60여 개 연산) — 행을 고르면 샘플 코드가 자동 실행
- 원본 / 실행 결과를 나란히 비교, Python 코드를 직접 고쳐서 실행 (Ctrl+Enter)
- 응용 방법별 최적 필터 조합 표 (등록·삭제, `pipelines.ini` 불러오기/내보내기)

### 이미지 수정 탭
- 32개 필터를 골라 순서대로 조합 (켜기/끄기, 순서 변경, 파라미터 슬라이더)
- 추천 조합 10종 (사진 보정, 문서 OCR, 저조도 엣지, 객체 분리 등)
- 원본 / 결과 비교 + 밝기·RGB 히스토그램과 통계
- 결과를 원본 해상도 PNG로 저장, 조합을 Python 코드로 보기

### 공통
- 이미지 변경(파일 선택·끌어다 놓기), 영역/열 너비 드래그 조절
- 무거운 연산은 백그라운드(Web Worker)에서 실행 — 오래 걸리면 상단 **중지** 버튼

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 웹 버전 프로그램 (이 파일 하나로 동작) |
| `KONG_이미지필터테스트_R09.py` | 원본 Python(tkinter) 데스크톱 버전 |
| `KONG_이미지필터테스트_R09.spec` | PyInstaller 빌드 설정 |
| `pipelines.ini` | 응용 필터 조합 데이터 |

## 요구 사항
- 최신 Chrome / Edge (인터넷 연결 필요: Pyodide CDN)
- Python 버전 실행 시: `opencv-python`, `numpy`, `Pillow`
